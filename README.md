# AOZORA RACING AI — private prototype v0.2

中央・地方競馬向けのAI分析Webアプリ試作一式。**公開販売可能な完成品ではありません。** 運営者が自ら利用権を持つデータでのみ分析してください。馬券の購入・代理購入機能はありません。

## 機能
- 黒×ゴールド、スマホ対応、全レース入力UI、券種・予算・最大点数指定
- 会員登録・ログイン（HTTP-onlyセッションcookie、bcrypt）と無料3回
- OpenAI APIによる説明付き分析（API接続時のみ）
- 購入ゲート：確認不足なら見送り、参考予想は表示
- 自分の推奨馬の独立評価（同一予想に含む）
- 収支帳：実購入と仮想の区分、的中率・回収率・損益、記録削除
- 予想履歴一覧、Stripe Checkout/顧客ポータル/Webhook基本実装

## 実行
1. Node.js 20+ が利用できるPCまたはクラウド環境へ展開
2. `npm install`
3. `.env.example` を `.env` に複製して値をセット（`.env`をGitHubに絶対アップロードしない）
4. 環境変数をロードし `npm start` 例：`node --env-file=.env server/index.js`
5. `http://localhost:3000` にアクセス

## 未接続 / 本番前必須
- **自動出馬表・馬体重・オッズ・調教・パドック取得は未接続。** データ提供事業者の利用許諾・契約・API仕様確認後に専用アダプタを追加（`GET /api/race/:key` は未接続エラーを返す）。AIによる検索だけでは確かなデータソースの代替にはなりません。
- **実シミュレーション計算エンジン未実装。** 入力チェックのチェックボックスは実計算の証明になりません。購入ゲートは自動的にGOを出さず `HOLD` または `REVIEW_REQUIRED` のみ。
- **予想時の利用上限の強制は未実装。** 3プランの月10/50/150回、更新・返金・解約後の認可の徹底、利用量台帳、Stripe webhook完全性を追加するまで課金を開始しないこと。
- **CSRF防御が未完成。** 商用公開前にはセッション認証のCSRF対策、メール認証、パスワード再設定、アカウント削除、監査ログ、監視、暗号化バックアップ、プライバシーポリシー/特商法表記、個人情報保護対応が必要。
- 競馬予想プラグインの最新版全文は未取得。今回参照できた地方競馬改善資料のルールをプロンプトに暫定反映したが、定量スコアや本番推論器は**仮実装**。中央向けと地方向けの判定仕様は分離のうえ移植が必要。
- 複数同時実行へのトライアル消費アトミック処理、決済二重反映、エラー表示、利用規約、テスト体制を追加すること。
- GitHub PagesでAPIやシークレットを実行しないこと。プライベートリポジトリに保管し、商用対応のアプリサーバーで運用。

## セキュリティ
サーバーの秘密鍵は `.env` にのみ保存。APIキーをHTMLや公開GitHubへ書かない。Stripe秘密鍵・Webhook署名検証はサーバーのみ。信頼できない出走データはAIプロンプト内のデータとして扱う。**馬券購入の自動化はしない。**
